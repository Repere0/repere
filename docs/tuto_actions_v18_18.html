Les actions à faire,
dans l'ordre où elles comptent.

Neuf étapes. Les quatre premières prennent vingt minutes et retirent une exposition juridique réelle. Les cinq suivantes peuvent attendre le week-end. Chacune dit pourquoi, quoi taper, comment savoir que c'est réussi et où est le piège.

Ce qui est vrai en ce moment

Le site en ligne est encore la v18.14. Il affiche 1,99 €/mois, un bouton « S'abonner » et un tunnel de paiement — pour un service qu'aucune structure juridique ne peut vendre. Tout le travail des deux derniers jours ne réduit ce risque qu'à l'étape 4.

1

Mettre ton dépôt à jour

1 minute
Pourquoi

J'ai vérifié : ton clone local n'a ni outils/agenda_an.json ni dossier data/. La collecte quotidienne tourne sur GitHub et commite chaque matin, mais tu n'as jamais récupéré ces commits. Sans ça, tu ne peux pas reconstruire l'app avec les données du jour.

:: ouvre l'invite de commandes, puis
cd C:\Users\APina\repere
git pull
Réussi si

La sortie mentionne outils/agenda_an.json et data/journal_collecte.json, et git log --oneline -5 montre des commits « Collecte du … ».

Piège

Si git pull répond « Your local changes would be overwritten », c'est que je viens d'écrire des fichiers que le distant a aussi modifiés. Tape git stash, puis git pull, puis git stash pop. Si un conflit apparaît, ne bricole pas : envoie-moi la sortie exacte.

2

Commiter ce que je viens de déposer

5 minutes
Pourquoi

Deux fichiers manquaient au dépôt : site/index.html et app_repere_v18_9.html.bak. Ce sont la référence et la source de la preuve que build_pwa exige avant de produire quoi que ce soit. Sans eux, la reconstruction automatique échouait chaque matin — la collecte tournait dans le vide. Ils font 16 Mo chacun, ne changeront jamais, et c'est le prix d'une garantie qui se vérifie tous les jours.

git add -A
git status
git commit -m "v18.18 : mise en veille, correctifs juridiques, collecte servie"
git push
Réussi si

git status, avant le commit, liste bien app_repere_v18_18.html, site/index.html, app_repere_v18_9.html.bak, les quatre fichiers de outils/ et les deux documents de docs/. Après le push, git status dit « nothing to commit, working tree clean ».

Piège

Le push envoie environ 50 Mo : compte une à trois minutes, et ne l'interromps pas. Si GitHub refuse pour cause de taille, dis-le-moi — on passera la preuve en option explicite plutôt que de bricoler Git LFS.

3

Poser le nouveau workflow

2 minutes
Pourquoi

La version 1 collectait et s'arrêtait. La version 2 reconstruit et déploie : depuis que l'agenda est servi à part, Netlify n'envoie que les fichiers modifiés, soit 650 Ko par jour au lieu de 17 Mo. L'arbitrage sur la taille qui bloquait cette étape n'a plus d'objet.

Dans l'explorateur : copie docs\collecte_workflow_v2.yml.txt par-dessus .github\workflows\collecte.yml, en le renommant. Puis :

git add .github/workflows/collecte.yml
git commit -m "Workflow v2 : la collecte atteint le site"
git push
Réussi si

Onglet Actions du dépôt : le workflow apparaît toujours, sans bandeau rouge d'erreur de syntaxe. L'étape « Déployer sur Netlify » sera sautée tant que les secrets n'existent pas (étape 6) — c'est voulu, le job reste vert.

4

Déployer la v18.18 — l'étape qui compte

5 minutes
Pourquoi

C'est la seule action de cette liste qui change quelque chose pour un visiteur aujourd'hui : elle retire du site public le prix, le bouton d'abonnement, l'écran de paiement, la case d'âge, les réglages de notification qui n'envoient rien, et les quatre contenus étiquetés DÉMO ou À RECROISER.

Décompresse repere_site_v18_18.zip, va sur ton site Netlify, onglet Deploys, et glisse-dépose le contenu du dossier dans la zone de dépôt.

Piège — celui-là fait perdre une heure

Glisse le contenu (index.html, accueil.html, sw.js, donnees/, icones/…), pas le dossier qui les contient. Sinon Netlify publie un site dont la racine est un dossier, et tu obtiens une page blanche ou une liste de fichiers.

Réussi si

Sur le site, cherche « 1,99 » avec Ctrl+F : aucun résultat. Dans l'écran Sources, le pied de page dit « Repère v18.18 ». Dans l'agenda parlementaire, le panneau de couverture affiche « Dernière collecte » avec une date.

5

Vérifier sur ton téléphone

3 minutes
Pourquoi

Ton téléphone est le seul appareil dont on sait qu'il a déjà installé une ancienne version. Le service worker sert depuis son cache : si l'empreinte n'a pas changé, il continuerait à servir la v18.14 avec l'écran de paiement, indéfiniment. L'empreinte a bien changé (repere-d39cdab38722), mais c'est à vérifier sur un vrai appareil, pas à supposer.

  • Ouvre le site, puis ferme complètement l'app installée et rouvre-la.
  • Cherche le pied de page « Repère v18.18 ». S'il dit encore 18.14 ou 18.15 : réglages du navigateur → vider les données du site, ou désinstaller puis réinstaller depuis l'écran d'accueil.
  • Mets l'avion, rouvre : l'app doit fonctionner, et l'agenda doit dire calmement qu'il n'est pas chargé plutôt que tourner dans le vide.
6

Créer les deux secrets Netlify

10 minutes
Pourquoi

Sans eux, le workflow reconstruit le site chaque matin et le jette. Avec eux, l'agenda parlementaire du jour est en ligne à 6 h, sans que tu touches à rien.

SecretOù le trouver
NETLIFY_AUTH_TOKENNetlify → ton avatar → User settings → Applications → Personal access tokens → en créer un, avec une date d'expiration.
NETLIFY_SITE_IDSur ton site → Site configuration → General → Site details. Netlify a renommé « Sites » en « Projects » : selon la version de l'interface, tu liras peut-être Project ID. C'est la même valeur.

Puis, sur GitHub : dépôt → Settings → Secrets and variables → Actions → New repository secret, une fois par secret, en respectant exactement les deux noms ci-dessus.

Règle sans exception

Ces deux valeurs ne doivent apparaître nulle part ailleurs que dans le formulaire de GitHub. Ni dans un fichier du dépôt, ni dans une note, ni dans une conversation — y compris avec moi. Un jeton Netlify collé une fois quelque part est un jeton à révoquer. Si ça arrive : User settings → Applications → révoque-le et recrée-en un.

7

Lancer le workflow à la main, et lire ce qu'il dit

5 minutes
Pourquoi

Ne pas attendre 5 h 47 du matin pour découvrir qu'une étape casse. Et surtout : c'est la première fois que la chaîne complète — collecte, normalisation, reconstruction, déploiement — tourne d'un bout à l'autre.

Dépôt → Actions → Collecte quotidienne → Run workflow.

Réussi si

Trois lignes précises dans le journal :

  • agenda : 6xxx reunions, 3xx instances, collecte du 2026-08-…
  • agenda servi : 6xx Ko, depuis la collecte du 2026-08-…
  • site : agenda du 2026-08-…, 6xxx reunions

La troisième est celle qui compte : elle prouve que le site servira le fichier du matin et non la copie figée dans les 17 Mo. Si la date affichée n'est pas celle du jour, le job échoue exprès.

Piège

Si « Télécharger les sources » passe en orange, ouvre data/journal_collecte.json dans le dépôt : chaque échec y est daté avec son message. Une source de l'Assemblée indisponible un matin est normale ; trois matins de suite ne l'est pas.

8

Me déposer le fichier des scrutins

2 minutes
Pourquoi

C'est la réponse directe à « l'app est pauvre en informations actuelles ». Un scrutin est daté, officiel, nominatif, et territorial : le vote de ton député, pour les 577 circonscriptions d'un coup, sans écrire une ligne d'éditorial. Ta collecte télécharge déjà ce fichier chaque matin — et le job le jette à la fin.

Je ne peux pas le télécharger d'ici : mon conteneur reçoit un 403 de data.assemblee-nationale.fr, et la page officielle ne documente pas les noms de champs. Écrire l'ingestion sans avoir vu le fichier, ce serait deviner.

Télécharge Scrutins.json.zip depuis data.assemblee-nationale.fr (rubrique Travaux parlementaires → Votes) et pose-le dans C:\Users\APina\repere\data\. Crée le dossier s'il n'existe pas.

Réussi si

Tu me le dis. Je vérifie le schéma champ par champ, j'écris outils/scrutins_an.py avec les mêmes contrôles indépendants que l'agenda, et le fil se remplit pour toute la France.

Ce que je refuserai d'en faire

Aucun décompte de présence, aucun taux d'absence, aucun classement de députés. Un compteur d'absences est un classement déguisé, et les données de présence de l'Assemblée ne sont pas fiables. Le vote, oui : c'est un fait. Le jugement, non.

9

Montrer l'app à cinq personnes

une soirée
Pourquoi

C'est l'action la plus importante de la liste, et la seule qui ne soit pas technique. Toute la mise en veille a servi à ça : tu peux maintenant tendre ton téléphone sans avoir à expliquer ce qui est faux dedans. Tu es à quatre mois de la bêta de décembre, et le risque principal n'est plus technique — c'est de construire longtemps pour quelqu'un que tu n'as jamais regardé se servir de l'app.

  • Ne montre rien, ne commente rien. Donne le téléphone et tais-toi.
  • Une seule consigne : « trouve qui est ton maire, et où va l'argent de ta commune ».
  • Note deux choses seulement : où la personne hésite, et le premier mot qu'elle ne comprend pas. Le mot « échelon » est mon pari.
  • Ne corrige rien pendant. Ne promets rien après.
