1

Poser la dernière version du workflow

2 minutes
Ce qu'elle ajoute

Deux choses. Une étape qui décrit le fichier des scrutins — tu n'as plus rien à télécharger, le runner le fait pour moi. Et un git pull --rebase avant le push, qui règle définitivement l'échec de 9 h 18 : ton propre push avait fait bouger la branche pendant l'exécution, GitHub avait refusé celui du robot, et le job était passé au rouge pour une raison sans rapport avec la collecte.

copy /Y docs\collecte_workflow_v2.yml.txt .github\workflows\collecte.yml

Puis le contrôle, seul :

findstr /C:"Decrire le schema des scrutins" .github\workflows\collecte.yml
Réussi si

La deuxième commande affiche une ligne. Si elle n'affiche rien, arrête-toi : la copie a pris le mauvais fichier, dis-le-moi.

Ensuite seulement, l'envoi :

git add .github/workflows/collecte.yml outils/echantillon_scrutins.py && git commit -m "Schema des scrutins ; rebaser avant de pousser" && git push
Piège

Le fichier à copier est celui de docs\, pas celui que tu avais téléchargé dans data\ — ce dernier est l'ancienne version, buggée. Si tu l'as encore : del data\docs_collecte_workflow_v2.yml.txt

2

Relancer le workflow, et lire trois lignes

5 minutes
Pourquoi

C'est le lancement qui répond à tout d'un coup : est-ce que la chaîne complète tourne, est-ce que tes secrets Netlify sont bons, et est-ce que j'obtiens le schéma des scrutins.

github.com/Repere0/repere/actions/workflows/collecte.yml → bouton Run workflow.

Réussi si — les trois lignes à chercher
  • schema ecrit : docs/schema_scrutins.md (…)
  • site : agenda du 2026-08-…, 6xxx reunions — celle-ci prouve que le site servira le fichier du matin, pas la copie figée dans les 17 Mo
  • l'annotation « Site reconstruit et publié sur Netlify »
Si tu lis « non publié, secrets absents »

C'est que les deux secrets manquent ou qu'un nom est mal orthographié. Va à l'étape 3. Le reste du job aura quand même réussi — seule la publication est sautée.

3

Les deux secrets Netlify — seulement si l'étape 2 le demande

10 minutes
Pourquoi

Sans eux, le workflow reconstruit le site chaque matin et le jette. Avec eux, l'agenda parlementaire du jour est en ligne à 6 h sans que tu touches à rien.

  • Le jeton — app.netlify.com/user/applications → New access token, description « GitHub Actions Repère », avec une date d'expiration. La valeur ne s'affiche qu'une fois : garde l'onglet ouvert.
  • L'identifiant du site — app.netlify.com/sites/repereapp/configuration/general → section Site information (ou Project information : Netlify renomme « Sites » en « Projects »). C'est le Site ID, une longue suite de lettres, chiffres et tirets.
  • Les déposer — github.com/Repere0/repere/settings/secrets/actions → New repository secret, deux fois.

Les noms doivent être exactement ceux-ci, majuscules et tirets bas compris :

NETLIFY_AUTH_TOKEN
NETLIFY_SITE_ID
Règle sans exception

Ces deux valeurs ne vont que dans le formulaire de GitHub. Jamais dans un fichier du dépôt, jamais dans une note, jamais dans une conversation — y compris avec moi. Un jeton collé une fois quelque part est un jeton à révoquer.

Une fois créés, relance le workflow (étape 2) et vérifie que l'annotation dit maintenant « publié ».

4

Ton téléphone

3 minutes
Pourquoi

C'est le seul appareil dont on sait qu'il a déjà installé une ancienne version. Son service worker sert depuis son cache : sans vérification, il pourrait continuer à afficher l'écran de paiement pendant des semaines.

  • Ferme complètement l'app installée, puis rouvre-la.
  • Onglet Moi, descends. Tu dois lire « Ce que coûte Repère — Rien. Repère est gratuit, en entier, et ne vend rien. » Si tu lis encore « Premium — 1,99 € / mois », vide les données du site dans les réglages du navigateur, ou désinstalle et réinstalle.
  • Mets l'avion et rouvre : l'app doit fonctionner, et l'agenda doit dire calmement qu'il n'est pas chargé au lieu de tourner dans le vide.

Me dire que c'est vert

10 secondes
Ce que je fais ensuite

Dès que docs/schema_scrutins.md apparaît dans le dépôt, je le lis et j'écris outils/scrutins_an.py sur des noms de champs lus, pas devinés. C'est ce qui remplit ton fil d'informations datées et territoriales — le vote de ton député, pour les 577 circonscriptions d'un coup, sans écrire une ligne d'éditorial.
